# 🚀 Pi Explorer

**The premier dApp Directory and Blockchain Browser for the Pi Network Ecosystem.**

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Platform: Pi Network](https://img.shields.io/badge/Platform-Pi%20Network-purple)](https://minepi.com/)

## 🌟 Overview
Pi Explorer is a decentralized gateway designed to empower the Pi Network community. It serves two primary purposes:
1. **Explorer:** Providing real-time visibility into the Pi blockchain.
2. **dApp Catalog:** A curated, community-driven directory of decentralized applications where users can discover, rate, and boost their favorite projects.

## ✨ Key Features
- **Decentralized dApp Directory:** Discover new projects in DeFi, Gaming, Social, and more.
- **Community Voting System:** Support your favorite dApps using Pi.
- **Rank & Boost Mechanism:** A transparent ranking system based on community engagement and Pi-powered boosts.
- **Multi-language Support:** Accessible to a global audience (EN, FA, TR, AR, ZH).
- **Real-time Insights:** (Upcoming) Tokenomics dashboards and DePIN node tracking.

## 🛠 Tech Stack
- **Frontend:** React, TypeScript, Vite
- **Styling:** Tailwind CSS
- **State Management:** Zustand & TanStack Query
- **Backend/Database:** Supabase (PostgreSQL & Edge Functions)
- **Blockchain Integration:** Pi Network SDK

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- Pi Browser (for testing blockchain features)

### Installation
1. Clone the repo: `git clone https://github.com/yourusername/pi-explorer.git`
2. Install dependencies: `npm install`
3. Setup Environment Variables: Create a `.env` file and add your Supabase credentials.
4. Run development server: `npm run dev`
